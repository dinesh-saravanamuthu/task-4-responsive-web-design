# Task 4 – Make a Website Mobile-Friendly Using CSS Media Queries

## Objective
Convert a desktop-style webpage into a mobile-friendly responsive layout using CSS media queries.

## What was implemented
- Added the viewport meta tag for proper mobile scaling.
- Used flexible containers with percentage and `min()` sizing.
- Used CSS Grid and Flexbox for adaptable layouts.
- Added a primary responsive breakpoint at `max-width: 768px`.
- Stacked desktop columns vertically on smaller screens.
- Reduced mobile spacing and typography.
- Made the navigation wrap/stack on mobile.
- Made the preview layout change from 3 columns to 1 column.
- Used `max-width: 100%` for image-safe responsive behavior.
- Added a second breakpoint at `max-width: 480px` for small phones.
- Prevented horizontal overflow with `overflow-x: hidden`.

## Files
- `index.html` – responsive webpage structure
- `style.css` – desktop and mobile responsive styles
- `README.md` – task explanation

## How to run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. Resize the browser window or open Chrome DevTools.
5. Select a mobile device and verify the layout at widths below 768px.
